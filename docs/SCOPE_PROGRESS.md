## 機能拡張ログ

### ✅ 配置表：下にメモ枠・マスに直接入力・工事を左から隠す（2026-08-05 / main）
- **表の下にメモの記入枠**：表示中の2週間ごとに1枚、自由に書ける（改行そのまま）。打っている間に自動保存し、枠から離れたときにも保存する（「保存しました」を右下に表示）。週を切り替えるとその週のメモに入れ替わる
- **印刷にもメモが一緒に出る**：入力欄は入りきらない分が刷られないため、同じ本文を `.hm-print` に別出しして枠線付きで刷る
- **マスに直接入力**：研修・イベントの手伝いなど現場でない日を、**工事を選んでいない状態でマスをタップ**するとその場に書ける（Enterで確定・Escでやめる・空で確定すると消える）。工事を選んでいるときは今までどおり置くだけなので既存の操作は変わらない。書いた名前は左のコマ置き場にも自動で並び、他の日にも置ける
- 日本語入力の変換確定Enterで誤確定しないよう `onCompositionStart/End` で抑止（工事一覧の検索と同じ流儀）
- **終わった工事を左から隠す**：左の各工事の「隠す」で消せる（工事一覧のステータスは変えない）。「隠した工事」から戻せる
- **完了しても工事名を残す**：工事を全件読み込み、過去のコマが「（終了した工事）」にならないようにした。色は工事IDから決めるので一覧の並びで色が変わらない（印刷済みの表と食い違わない）
- 保存はタスクDB相乗り（メモ=`ref_type='メモ'` + `ref_id='配置:週の起点日'`・本文は備考／現場以外のコマ=`notes='L:名前'`／隠す印=`ref_id='__hidden__'`）。**新APIファイル0個**（Vercel 12関数上限を維持）
- 本番E2E検証済み（メモ保存・改行保持・週切替・マス直接入力の新規/編集/削除・印刷レイアウトを実データで確認 → テストデータ削除済み）

### ✅ 工事一覧に住所を表示・検索まわりの改善（2026-08-02 / main）
- **工事一覧に工事場所（住所）を表示**：件名のすぐ下に📍付きで1行。長い住所は2行までで省略（`.project-row-loc`）
- **絞り込み・検索条件をURLに保持**（`useSearchParams`）：工事詳細から「戻る」で選んだ絞り込みがそのまま復元される。履歴は `replace` で増やさない
- **検索中は絞り込み・拠点を無視して全工事から探す**（以前はANDだったため入金済み・別年度・別拠点が出てこなかった）。検索対象に担当者を追加、検索中は絞り込みタブを隠す
- **検索欄に「×（検索をやめる）」ボタン**を追加
- **住所で検索できることを明示**（案内文を「工事名・お客様名・住所・担当者で検索」に）。あわせて表記ゆれを吸収する `normalizeForSearch()` を追加：全角英数→半角・各種ハイフン/長音を `-` に統一・空白は無視。住所の「１−２−３」「1-2-3」どちらでもヒットする
- **スペース区切りはAND検索**（例：「盛岡 外壁」で両方を含む工事）
- 新APIファイル 0個。本番反映確認済み

### ✅ 車検をカレンダーに自動表示・「あと◯日」表示（2026-07-30 / feature/vehicle-inspection-calendar）
- **車検日がそのままカレンダーに出る**（`Calendar.tsx` に `vehicle` 種別を追加）。コピーを作らないので、車検一覧で車検日を直せばカレンダーも追従する
- **「カレンダーに登録」ボタンを車検から廃止**（押し忘れ・日付ズレの原因だったため）。資格・議題は従来どおりボタン方式
- **「あと◯日」**を 車検一覧（常時表示に変更）／カレンダー／ホームの3か所に表示。残り日数の計算・表示は `lib/meeting.ts`（`daysUntil`/`countdownLabel`/`VEHICLE_SOON_DAYS`）に一本化
- **ホームに「車検が近い車両」**を追加（60日以内＋超過分がある時だけ表示）
- 拠点なしの車両は全社共通のため、本社/釜石選択時も表示（`CalEvent.always`）
- 新APIファイル 0個（Vercel 12関数上限を維持）。本番E2E検証済み（テストデータ作成→表示確認→削除）
