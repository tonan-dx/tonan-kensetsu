## 付録

### 開発フロー
```
Phase 1: 要件定義 → Phase 2: Git管理 → Phase 3: フロントエンド基盤 → Phase 4: ページ実装
→ Phase 5: 環境構築 → Phase 6: バックエンド計画 → Phase 7: バックエンド実装
→ Phase 8: API統合 → Phase 9: E2Eテスト → Phase 10: ローカル動作確認 → Phase 11: デプロイメント

※ サポートツールは必要に応じて適宜使用
```

### 開始手順

開発プロンプトをクリックして「Phase 1: 要件定義」を選択し、要件定義エンジニアを活用するところから始めてください。各フェーズが完了したら、次のPhaseへ進みます。

サポートツールは開発中の任意のタイミングで、問題解決や品質向上のために使用できます。

## 機能拡張ログ

### ✅ 金曜会議機能・工事の進行率（2026-07-24 / feature/weekly-meeting-progress）
- **会議ページ新設**（下ナビ「会議」）：今週の議題（各自が事前追加）＋議事録一覧
  - 議題＝タスクDB相乗り `ref_type='議題'`（新API 0個）
  - 議事録＝お知らせDB相乗り `種別=議事録`、回覧・添付は既存UIを流用（`/api/notices?kind=minutes`）
- **工事の進行率(0〜100%)**：工事DBに「進行率」フィールド追加。工事詳細でスライダー入力、工事一覧・詳細に進捗バー表示
- Vercel 12関数上限を維持（新APIファイル 0個）。本番E2E検証・デグレなし確認済み
- 実装詳細・落とし穴はメモリ `tonan-architecture-gotchas` を参照

### ✅ 車検をカレンダーに自動表示・「あと◯日」表示（2026-07-30 / feature/vehicle-inspection-calendar）
- **車検日がそのままカレンダーに出る**（`Calendar.tsx` に `vehicle` 種別を追加）。コピーを作らないので、車検一覧で車検日を直せばカレンダーも追従する
- **「カレンダーに登録」ボタンを車検から廃止**（押し忘れ・日付ズレの原因だったため）。資格・議題は従来どおりボタン方式
- **「あと◯日」**を 車検一覧（常時表示に変更）／カレンダー／ホームの3か所に表示。残り日数の計算・表示は `lib/meeting.ts`（`daysUntil`/`countdownLabel`/`VEHICLE_SOON_DAYS`）に一本化
- **ホームに「車検が近い車両」**を追加（60日以内＋超過分がある時だけ表示）
- 拠点なしの車両は全社共通のため、本社/釜石選択時も表示（`CalEvent.always`）
- 新APIファイル 0個（Vercel 12関数上限を維持）。本番E2E検証済み（テストデータ作成→表示確認→削除）

### ✅ 会議の日付管理・車検/資格リスト（2026-07-24 / 同ブランチでv2拡張）
- **会議を日付ごとに管理**：会議日一覧＋日付ごとの詳細（議題・議事録をその回に紐づけ）
- **車検一覧・資格試験一覧**を共通リストとして追加（毎週の会議画面に常時表示、車検日が近い/超過を強調）
- **議題・車検・資格の日付付き項目を「カレンダーに登録」ボタンで予定に飛ばせる**
- タスクDB相乗り（ref_type='議題'/'資格'/'車検'）。新APIファイル 0個。本番E2E検証・デグレなし
